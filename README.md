# 手势控制圣诞树

一个同时适配手机与电脑的交互式圣诞树网页项目。参考抖音视频《圣诞节快到了，这个圣诞树拿去发给她（他）》的视觉效果：黑色星空背景下，由密集暖色光点组成的锥形圣诞树，带 "MERRY CHRISTMAS" 艺术字与礼物盒点缀。

用户授权后可开启摄像头，通过手部动作隔空操控圣诞树；同时支持鼠标点击 / 手指点按圣诞树换色。两套交互互不冲突。

---

## 运行方式

### 电脑端（推荐）

摄像头 API 要求**安全上下文**，必须用 `localhost` 打开，不要直接双击 `index.html`。

```bash
cd /workspace/xmas-tree
python3.11 -m http.server 8080
```

浏览器访问：<http://localhost:8080>

点击页面上的 **开启摄像头手势控制**，在弹窗中允许摄像头权限即可。

### 手机端

手机浏览器需通过 **HTTPS** 访问才能使用摄像头，任选一种方式：

- 将本目录部署到任意静态托管服务（GitHub Pages / Vercel / Netlify 等），用 HTTPS 地址打开；
- 或用 HTTPS 内网穿透（ngrok、localtunnel 等）把本地 `8080` 端口暴露出去；
- 或在手机本地环境（如 Termux）起 HTTP 服务并用 `localhost` 打开。

> 若摄像头不可用或未授权，页面会给出明确提示；**点击 / 点按换色功能仍可正常使用**。

## 交互说明

### 手势隔空操控（需摄像头）

| 手势 | 效果 |
| --- | --- |
| 张开手掌 | 粒子展开为完整树形 |
| 握紧拳头 | 粒子向树身聚拢 |
| 左右移动手掌 | 旋转圣诞树 |
| 上下移动手掌 | 缩放树体 |
| 手靠近 / 远离摄像头 | 进一步放大 / 缩小树体 |
| 捏合手指（拇指 + 食指） | 触发一次绽放特效 |

摄像头预览窗口会实时叠加手部骨架，左上角显示当前识别到的手势状态。

### 点击 / 点按换色（无需摄像头）

- 电脑鼠标点击圣诞树、手机手指点按圣诞树，即可按顺序循环切换配色；
- 滑动 / 拖拽不会误触发换色；
- 配色共四态，固定循环、无随机变化：

| 顺序 | 状态 | 配色 |
| --- | --- | --- |
| 1 | 默认 | 参考图的暖色系：金黄、橙金、橙红为主，少量玫红与绿 |
| 2 | 蓝色 | 明亮蓝到深蓝 |
| 3 | 深绿 | 深绿色系 |
| 4 | 淡粉 | 淡粉 / 浅玫瑰色系 |

再点一次回到默认色。每个彩球的色号固定，切换只替换调色板，因此不会出现杂色或随机漂移。

### 一键隐藏界面

点击页面右侧的圆形眼睛按钮，隐藏顶部栏、控制面板、提示条与摄像头预览，画面只保留圣诞树；再次点击该按钮（或按 `Esc`）恢复。隐藏后圣诞树仍会自转，点击换色照常可用。

### 静止自转

没有手势输入时，圣诞树匀速缓慢自转，像 3D 展示一样；手势接管后完全跟随手，手离开画面后自动恢复自转。

### 流星与烟花开关

点击控制面板中的 **开启流星烟花** 按钮，画面开始随机播放两种特效（再次点击关闭）：

- **流星**：带细长渐变拖尾的蓝白色光迹，从夜空斜向划过；
- **烟花**：蓝白粒子在树的上方空中爆散，缓慢下落并淡出。

特效与换色、手势、自转互不干扰；开启后即使隐藏界面，流星与烟花仍会继续播放。

### 互不冲突的设计保证

- 手势模块只输出「旋转 / 缩放 / 粒子聚散 / 绽放」四个控制量，**从不修改颜色状态**；
- 颜色状态唯一入口是画布上的指针点击事件；
- 摄像头预览面板是独立浮层，点击它不会误触发画布换色；
- 摄像头关闭或失败后，手势控制停用，但点击换色继续可用。

## 技术说明

- **渲染**：原生 Canvas 2D。彩球预渲染为带高光与阴影的贴图，按旋转后的深度排序绘制（近大远小、近亮远暗），形成体积感；手机端约 2000 球，电脑端约 3300 球。
- **手势识别**：MediaPipe Tasks Vision `HandLandmarker`，优先 GPU 后端，失败自动回退 CPU；按 `video.currentTime` 去重检测，避免重复帧浪费。
- **手势稳定性**：掌心坐标与张开度做指数平滑；捏合判定带滞回阈值，防止抖动误触发。
- ** Safari / iOS**：使用 `playsinline` + `muted` 保证内联自动播放；前置摄像头 `facingMode: 'user'`。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 点「开启摄像头」没反应 | 确认用 HTTPS 或 localhost 打开；检查浏览器站点权限 |
| 提示「摄像头被占用」 | 关闭正在使用摄像头的其他应用后重试 |
| 手势识别慢 | 属于正常现象，首次加载模型约需数秒；CPU 后端比 GPU 慢 |
| 看不到手骨架 | 确认光线充足、手部完整出现在预览画面内 |
| 手机树被底部面板挡住 | 竖屏下树已上移；横屏会自动采用紧凑布局 |
